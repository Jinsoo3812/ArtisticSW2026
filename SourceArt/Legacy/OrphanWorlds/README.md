# 원본 맵이 없는 외부 패키지 보존

이 폴더는 검토 패키지가 아니다. 실제 프로젝트에서 더 이상 연결될 원본 맵이 없고 활성 참조도 없는 외부 액터/오브젝트 215개를 바이트 그대로 보존한다. 엔진의 콘텐츠 검색·cook 대상인 `Content` 밖으로 분리했으며 원본을 삭제하거나 빈 맵으로 대체하지 않았다.

원본 맵은 `/Game/Level/Level_JWJ`, `/Game/Pack_Simple_Particle_Burst/04_Maps/SImple_Particle_Burst_Showcased`다. 전체 Git 이력과 확인한 로컬 원본에 맵 파일이 없었다. 분리 전 하드·소프트·관리·검색 가능 참조를 조사했고 폴더 외부 참조는 0개였다. 운영 코드·설정의 맵 호출도 없었다. 선택적 원본 예제 검사 도구에는 부재 확인을 추가했다.

이는 **구조적 보존·격리**이며 없어진 맵 자체의 원인 복구라고 주장하지 않는다. 원본 맵을 확보하면 `ArchiveManifest.json`의 이전 경로·SHA-256을 사용해 엔진을 닫은 상태에서 원래 `Content` 경로로 복원할 수 있다. 덮어쓰기 전 같은 경로의 새 파일 유무와 소유 맵/의존성을 다시 확인한다. 전체 이동은 Git에서도 100% 동일 내용 rename으로 추적된다.
