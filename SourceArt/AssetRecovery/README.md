# 에셋 복구 근거

실제 수정은 프로젝트의 소스·`Content` 에셋에 반영했다. 여기에는 누락 경로의 이력, 복구한 커밋, 원본 해시와 이전 폴더→현재 정식 경로의 연결 근거를 보관한다. 별도 설치 작업은 필요 없다.

- `MissingAssetHistory.json`: 초기 누락 경로 52개 추적. 31개는 과거 커밋에서 원본을 찾았다. 옛 테스트 선체의 실제 4.8MB 메시와 추가 외부 액터는 이어진 의존성 추적으로 복구했다.
- `HistoricalRestoration.json`: 최초 복구 원본. 구형 BP/재질 중 현재 `Legacy` 또는 정식 경로가 있는 것은 중복 구형 구현을 늘리지 않고 표준 리다이렉터로 연결했다.
- `CanonicalRedirects.json`: 폴더 정리 커밋과 정식 목적지. BP는 원래 클래스/CDO 경로도 새 클래스로 해석됨을 검증했다.
- `OriginalSampleProvenance.json`: Git에 기록되지 않은 Foley enum은 로컬 GASP 원본에서 해시가 같은 파일을 복구했다. 원본 프로젝트의 엔진 연결 버전과 실제 파일 저장 버전은 구분했다.

`UnusedStateMachine`은 현재 프로젝트가 쓰지 않는 샘플 실험 상태머신의 복구 자료다. 상위 엔진 스키마를 그대로 복사하지 않고 독립 5.8 검사 프로젝트에서 설정을 추출해 5.7 객체로 재작성·대조했지만, 해당 DB를 운영 모션 매칭에 새로 끼워 넣지는 않았다. 원래 누락 상태에서 null이던 선택적 힌트는 유지한다. 51개 애니메이션은 로드된 노티파이 메타데이터가 전후 완전히 같은 정상 저장으로 잘못 남은 import만 정리했으며 포즈·커브·노티파이·그래프를 새로 작성하지 않았다.

현재 사용 중인 남녀 모션 매칭 DB와 그래프는 유지하고 실제 PIE 이동·점프로 재검증했다. 두 데모용 원본 리소스의 표준 기본값 연결과 215개 고아 패키지의 구조적 보존은 원본 복구와 별도로 [복구 안내](../../docs/Asset_Recovery_2026-11-01.md)에 기록한다.
