# 점프 중 방향 전환과 모션 연속성

이 프로젝트는 항상 Strafe를 사용한다. 점프 시작 모션은 Chooser에서 선택하여 Blend Stack으로 재생하며, 공중에서 마우스·키보드로 방향을 바꾸면 어울리는 F/L/R/B 모션을 다시 선택한다. `Project_J`의 회전 소유권과 방향 안정화 방식을 참고했다.

## 재생과 방향 선택

- F/FL/FR은 같은 F 모션, B/BL/BR은 같은 B 모션을 사용할 수 있다. 같은 Sequence를 선택하면 기존 플레이어·시작 핀·블렌드를 유지하고 Force Blend를 요청하지 않는다.
- 경과 시간은 항상 점프 진입 이후 시간이다. 다른 Sequence로 바뀔 때 재생 위치는 `Chooser 행 시작 시간 + 경과 시간`, 홀드 기간은 `Sequence 길이 - 행 시작 시간`으로 계산한다. F 행의 0.3초와 B 행의 0초가 반복 전환 중 누적되거나 시간을 되돌리지 않는다.
- 누락 행이나 이미 종료 직전인 목표 모션이면 기존 플레이어를 유지한다. 새 점프 이벤트는 같은 에셋이어도 정상적으로 다시 재생한다.
- 선택 방향을 기준으로 섹터 경계에 10도 여유를 두고, 새 방향이 0.04초 유지되어야 확정한다. 보호 구간에도 최신 방향을 추적하며 잠깐 스친 방향을 큐에 저장하지 않는다.
- 최초 진입을 포함한 실제 플레이어 블렌드가 기본적으로 완료된 후에 다음 모션을 허용한다. 모션 진행률 85% 이후에는 재선택하지 않는다. 별칭 행 선택은 블렌드 보호 시간을 다시 시작하지 않는다.
- 90도 전환은 최소 0.15초, 180도 전환은 최소 0.22초로 블렌드한다. Chooser가 지정한 더 긴 블렌드는 유지한다.
- 공중 방향 재선택은 도약 시의 발과 Gait를 유지한다. Sprint의 측면·후면 점프 제외 정책도 유지한다.
- `CharacterMovement::IsFalling()` 동안 캡슐 회전은 계속 보간하며 Controller Yaw와 번갈아 적용하지 않는다.

AnimInstance의 `StateController|Jump`에서 다음 값을 조절할 수 있다.

| 속성 | 기본값 | 의미 |
| --- | --- | --- |
| `StateControllerJumpAirMinBlendProgress` | 1.0 | 실제 블렌드 완료까지 보호. Project_J의 0.7 기준도 선택 가능 |
| `StateControllerJumpAirDirectionConfirmationTime` | 0.04초 | 새 방향 확정까지의 유지 시간 |
| `StateControllerJumpAirWideTurnBlendTime` | 0.22초 | 반대 방향 전환의 최소 블렌드 시간 |

## 워핑의 순간 반전 방지

실제 재현 로그에서는 에셋·재생 시간·블렌드가 이어지는 프레임에서도 루트·골반이 약 70~87도 바뀌었다. 해당 프레임의 Actor Yaw 변화는 약 1~8도였다.

UE 5.7의 Graph Orientation Warping은 루트 모션과 이동 방향의 차이가 90도 기준을 넘으면 워핑 목표를 180도 반전할 수 있다. 보간 속도가 0이고 하체 루트 분배 비율이 0.5일 때, +89도에서 -89도로 바뀌는 목표는 루트를 한 프레임에 89도 회전시킨다.

실제 Orientation Warping 노드에서 원래 보간 속도가 0 이하이면 공중·점프 시작·착지 동안만 보간 속도 10을 적용한다. 노출 입력 갱신 이후와 skeletal control 평가 사이에 적용한다. 착지에서 지상으로 넘어갈 때 0.2초 동안 유지한 뒤 원래 값을 복원한다. 원래 양수인 보간값은 그대로 유지하고 캐시 갱신 시에도 원래 값을 보존한다.

이 처리는 AnimInstance 런타임에만 적용한다. 90도 반전 기준, Chooser 행, Blend Stack 블렌드 시간과 에셋 설정은 유지한다. 진단용 로그·추적 상태·A/B 콘솔 제어는 제거했다.

## 검증과 변경 범위

최종 정리 후 UE 5.7 직접 UBT 빌드가 성공했고, 회귀 테스트 7개가 통과했다(실패 0개, 기존 누락 에셋 경고가 있는 테스트 1개). 빌드 로그는 `Saved/Logs/UBT_JumpAir_Cleanup_20261002.log`, 테스트 보고서는 `Saved/Automation/JumpAir_Cleanup_20261002/index.json`이다.

실제 UE 워핑 노드에 UEFN Mannequin의 뼈 매핑과 루트 모션 속성을 사용해 89→91도 경계를 평가했다.

| FPS | 기존 보간 0의 루트 변화 | 보간 10의 루트 변화 |
| --- | --- | --- |
| 30 | 89.000도 | 29.667도 |
| 60 | 89.000도 | 14.833도 |
| 120 | 89.000도 | 7.417도 |

사용자가 실제 에디터에서 빠른 공중 방향 전환의 개선을 확인했다. 자동화 그룹 `ArtisticSW.Animation.JumpAir`은 다음 회귀 검사를 포함한다.

- 방향 경계·후방 래핑, 보호 중 빠른 역회전과 방향 확정.
- 동일/누락 Sequence 유지, 시작 시간이 다른 행 사이의 재생 연속성.
- 실제 Chooser의 F/FL/FR 별칭과 F→R→B→F 전환, 발·Gait 유지, 새 점프 재시작.
- 실제 Chooser의 빠른 마우스·키보드 전환을 30/60/120 FPS에서 검사.
- 남성·여성 Blend Stack의 자동 시간 재동기화 계약.
- 남성·여성 실제 그래프의 공중 워핑 적용·착지 꼬리·지상 복원·양수 보간값 보존·캐시 갱신.
- 실제 UE 워핑 노드의 90도 경계와 반복 왕복.

변경 범위는 `BasePlayer.cpp`, `MotionMatchingAnimInstance.cpp/.h`, 내부 재선택 정책 헤더, 회귀 테스트와 문서다. 레벨·Chooser·Animation Blueprint·Sequence·Config는 수정하지 않는다. `Project_J`는 읽기 전용 참고이며 채영님의 `Lvl_CY`를 보존한다.
