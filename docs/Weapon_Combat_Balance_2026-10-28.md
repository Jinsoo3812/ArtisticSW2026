# 무기 전투 밸런스 계산 — 2026-10-28

## 사용한 실제 데이터와 계산 범위

- 실제 BP 기본 행은 주로 `/Game/GameplayAbilitySystem/Enemy/Data/DT_EnemyBaseStat`(단수)을 참조한다. `DT_EnemyBaseStats`(복수)도 읽었으며 현재 24행 수치는 동일하다. CSV만 보고 추정하지 않았다.
- BP_BasePlayerState 기본 Strength=10. 무기 장비 효과가 StrengthBonus를 더한다. 버프·도핑·시설 강화는 제외한다.
- 실제 GAS 공식은 `max(1, (10 + StrengthBonus) × AttackCoefficient × ChargeMultiplier)`. 이 보병 경로에는 방어력 감산이 없다. 현재 활 어빌리티의 최소·최대 충전 피해 배율은 모두 1이다.
- 지상·갑판·소환병·보스 24행을 모두 계산했다. 기본 체력 배율 1.0, 피해를 받을 수 있는 정지 표적, 빗나감·회피·이동·무적·패턴·렉이 없는 연속 명중 조건이다. 실제 플레이 측정값이 아닌 애니메이션 기반 계산값이다.
- 2인 값은 같은 무기의 두 사람이 동시에 공격하는 경우다. 필요 타격 수를 올림하여 나누므로 단순히 시간을 반으로 자르지 않는다.
- 원거리 첫 명중은 평지 10m / 실제 완충 속도 4000cm/s = 0.25초를 더했다. 중력 궤적·높이·네트워크/서버 후처리 틱은 이 근사에 포함하지 않는다.

발사 노티파이는 몽타주와 원본 클립에 중복되어 있지만 어빌리티의 bHasFiredCurrentShot 가드로 1발만 계산한다. 칼 역시 섹션별 LastOpenedComboIndex/히트 창 중복 방지에 맞춰 한 표적에 섹션당 한 타격으로 계산한다. 네 몽타주의 BlendOutTriggerTime=-1, BlendOut=0.25초, 자동 블렌드 아웃 ON을 확인했다. 기본 블렌드는 섹션 끝에 맞춰 완료되므로 후딜에 0.25초를 중복 가산하지 않는다.

칼 B 첫 콤보 확정 이벤트(0.399975초)가 첫 타격 창(0.400851초)보다 먼저 발생한다. 기존 코드는 다음 타를 예약한 인덱스와 현재 재생 섹션을 비교해서 버퍼 입력 시 첫 타를 버릴 수 있었다. 타격 소유 섹션을 실제 재생 섹션으로 판정하도록 수정하고, 중복 창·미예약 섹션 차단은 유지했다. 아래 '전' 값도 정상 타격 창을 가정한 기존 수치의 이론값이며, 이 버그가 있는 이전 플레이를 실측한 값이 아니다.

## 목표와 조정

- 일반 칼 A1의 기존 10 피해와 모션 주기를 시작점으로 유지했다. 최대 지속 DPS 목표는 성장 단계 0~4에 대해 약 8.96 / 13 / 20 / 28 / 36.
- 활은 거리 이점을 감안해 근접 목표의 약 95%를 목표로 하되 실제 충전·후딜을 포함한다. 단궁은 더 빠르고 장궁은 한 발이 더 강하다.
- 칼 B는 실제 모션상 빠른 콤보형이다. 단타 모션의 칼 A와 동일 타격 피해를 주면 DPS가 과도해지므로 콤보 프로필 공격 계수는 0.60으로 보정했다. 칼 A2도 기존 칼 B 프로필을 쓰므로 같은 보정을 적용한다. 애니메이션 에셋과 콤보 연결 방식은 유지하며, 위 타격 창 판정 오류만 바로잡았다.
- 성장 단계는 기존 ProgressionTier=0~4를 사용한다. 단계 0·1은 T1, 단계 2는 T2, 단계 3은 T3, 단계 4는 T4와 비교한다.
- 기존 카탈로그의 2번 무기=Rare, 3번 무기=Relic이라는 유물/희귀 표기 역전은 이번 수치 작업에서 변경하지 않았다. 따라서 아래 표는 등급명 대신 기존 아이템 식별자를 사용한다. 제작·획득 조건은 그대로 유지된다.

## 확인이 필요한 실제 배치

BP_Boss_Mid_1~3와 BP_Boss_Final은 각각 T1~T4 보스 행을 참조한다. 반면 T2_BP_ShipBoss_Rogue 기본 행은 비어 있고 T4_BP_ShipBoss_Samurai 기본 행은 T1_Boss다. 스폰/조우 컴포넌트에서 행을 덮어쓰면 정상일 수 있으므로 이번 작업에서 적 설정을 자동 수정하지 않았다. 실제 배치의 스폰 행·HealthMultiplier·보스 무적 구간은 별도 플레이 검증 대상이다.
