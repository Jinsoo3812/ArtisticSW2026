# 로딩 화면 편집

콘텐츠 브라우저: `/Game/Blueprints/02_UI/UI_Loading/WBP_LoadingScreen`

부모 클래스: `SWLoadingScreenWidget`. Event Graph 연결 없이 동작합니다.

## 디자이너

- `BackgroundImage` (Image): 목적지 사진이 표시되는 자리. 위치·크기·앵커를 편집하세요. Brush에 지정한 이미지는 목적지가 아직 확인되지 않았거나 매칭 항목이 없을 때의 기본 배경입니다.
- `LoadingMessageText` (Text Block): 안내 문구 자리. 디자이너의 Text에 입력한 문구가 기본값입니다. 줄바꿈·폰트·위치 등을 자유롭게 편집할 수 있습니다.
- `LoadingStatusText` (Text Block, 선택): 접속/플레이어 준비/귀환/출항 등 현재 상태를 표시합니다. 자동 갱신되므로 고정 안내 문구는 LoadingMessageText에 작성하세요. 이 위젯은 필요 없으면 삭제할 수 있습니다.

필수 위젯 이름 BackgroundImage와 LoadingMessageText는 유지하세요. Brush/Text에 별도의 BP 바인딩을 걸면 C++ 갱신과 충돌할 수 있으므로 사용하지 마세요.

## 목적지별 설정

WBP의 **Class Defaults → Loading → Destinations**에 항목을 추가합니다.

1. Level: 목적지 레벨 에셋 선택.
2. Background: 해당 레벨 사진을 임포트한 Texture2D 선택.
3. Message: 그 목적지에서 보여 줄 문구 입력. 비워 두면 디자이너의 기본 문구를 사용합니다.
4. Compile / Save.

같은 Level은 한 번만 등록하세요. 중복 시 첫 항목을 사용합니다. Background를 비우면 디자이너 기본 배경을 사용합니다. 생성된 에셋은 검은 기본 배경을 사용하며 실제 레벨 사진은 사용자가 지정해야 합니다.

## 동작 및 범위

- 기존 서버 접속, 로비 복귀, 귀환/최종 출항 로딩 흐름에 연결되어 있습니다.
- IP/참가 코드 접속 직후에는 서버의 목적지를 모르므로 기본 배경을 표시합니다. 엔진의 맵 로드 직전 이벤트에서 목적지를 받아 배경과 문구를 선택합니다.
- 현재 귀환과 최종 출항은 같은 맵을 재시작하므로 같은 레벨 사진을 사용하고 상태 문구로 구분합니다.
- 사진은 WBP의 참조로 미리 로드합니다. 선택한 목적지 월드 자체를 미리 로드하지 않습니다. 사진 수와 해상도에 따라 메모리 사용량이 늘어납니다.
- 맵 로딩 중에는 정적 화면을 표시합니다. 게임 스레드를 사용하는 WBP 애니메이션이나 실제 진행률 표시는 이번 구현 범위에 포함되지 않습니다.
- 패키징 대상에 WBP를 포함했습니다. 사진은 WBP의 에셋 참조로 함께 포함됩니다.
- 로비 UI 자체는 이번 변경에 포함되지 않습니다.

## 검증 방법

서로 다른 두 목적지에 사진과 문구를 지정하여 접속/로비 복귀를 확인합니다. 미등록 목적지에서는 기본 사진·문구로 돌아오는지, 플레이 준비 완료 후 로딩 화면이 사라지고 입력이 복구되는지 확인합니다.

에셋을 새로 생성해야 할 때는 `SWLoadingScreenSetup` 커맨드릿을 사용합니다. 기존 디자이너 레이아웃은 덮어쓰지 않고 컴파일·저장만 수행합니다.
