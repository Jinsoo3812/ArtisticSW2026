# Boss 순간이동 후 보행면 복구

2026-10-10 구현. 범위는 공통 Vanish Relocation Task를 사용하는 Vanish, VanishV2, ChainVanish, ChainSlashDash이다.

## 검사와 복구 흐름

1. 순간이동 호출 직후 실제 발 위치에서 보행면을 한 번 질의한다. 은신 중 검사 결과는 안전 위치 기록에 사용하며 연속 실패 횟수에는 합산하지 않는다.
2. 은신 상태에서는 이동 Base에 대한 상대 좌표를 저장한다. 재등장 시 현재 Base transform을 적용해 배의 이동·회전을 반영한다. 이 단계에서는 보행면을 질의하거나 검증하지 않는다.
3. 가시성·충돌 복원 직후 실제 발밑을 새로 질의한다. 이전 CharacterMovement CurrentFloor를 재사용하지 않는다.
4. 정상 지지가 있으면 검사를 즉시 종료한다. 없으면 기본 0.1초 간격으로 반복하고, 재등장 직후 검사를 포함해 3회 연속 실패하면 복구한다. 기본 발 아래 허용 간격은 15cm이며 위쪽 관통 오차는 10cm까지 허용한다.
5. BT를 일시 중지하고 현재 보스 전투 Ability만 취소한 뒤 재은신한다. 같은 Surface의 원래 목적지 주변, 기록된 안전 위치 주변, 스폰 지점 주변에서 유효한 보행면을 찾고 예약한다. 현재 보스의 접지나 플레이어 타깃, 보행 경로는 복구 목적지의 필수 조건이 아니다.
6. 현재 함선 좌표계로 목적지를 이동한 뒤 재등장하고 같은 방식으로 검사한다. 성공 시 예약·복구 태그를 정리하고 BT를 다시 판단한다. 복구 자체가 추가 공격이나 스킬 쿨다운을 소비하지 않는다.

복구는 기본 최대 3회, 총 2초로 제한한다. 모든 후보가 차단되거나 제한을 초과하면 숨김을 해제하고 전투를 정지하며 Error 로그를 남긴다. 사망·보상 처리를 임의로 발생시키지 않는다. 기존 공격 취소에 따른 기존 쿨다운 처리는 유지한다.

보행면 NotReady는 이탈 횟수에 포함하지 않는다. 일반 검사에서는 최대 1초 이상으로 제한된 준비 대기 후 종료하며, 복구 중에는 총 복구 제한 시간을 따른다. 새 은신은 이전 검사 타이머를 중지한다. 사망·함선 파괴·EndPlay·초기화·룸 복원은 복구 자원을 정리한다.
