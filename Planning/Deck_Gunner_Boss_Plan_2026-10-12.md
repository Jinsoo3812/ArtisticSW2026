# 갑판 원거리 총기 보스 개발 계획안

작성일: 2026-10-12. 이 문서는 개발 제안이며 아래 클래스명·설정값은 신규 구현을 위한 가칭 및 초기 테스트값이다.

2026-10-13 구현 변경: 조준선은 별도 Warning Mesh/Effect 대신 클라이언트의 직접 선 렌더링을 사용한다. 표시용 BP/자산 연결은 제거했고 `GunnerBossCombatData.Ray`에서 빨간 선의 색·두께를 설정한다. `LockTime = 0`이면 발사 직전까지 타깃을 추적한다. 총 외형은 기존 BaseWeapon/Weapon Registry로 연결한다. 현재 연결 방법은 `docs/Gunner_Boss_Editor_Setup.md`를 기준으로 한다.

## 1. 목표와 개발 범위

플레이어와 거리를 유지하다가 멈춰 조준선을 보여주고, 준비 시간이 끝나면 즉시 판정하는 총기 보스를 만든다. 플레이어는 조준선을 보고 옆으로 피하거나, 보스가 멈춘 동안 접근하여 공격한다.

- 기본 공격: 예고 후 단발 Hitscan 사격.
- 능력 1: 같은 사격 구조를 사용하는 3연속 정밀 사격.
- 이동: 갑판의 안전한 보행 경로를 따라 거리 유지.
- 딜타임: 모든 사격 준비 및 후딜 동안 이동 정지, 피해 수신 가능.

첫 버전에는 추가 능력, 체력별 페이즈, 소환, 순간이동, 신규 그로기 게이지를 넣지 않는다. 능력 1도 Projectile 없이 구현한다.

## 2. 전투 순환과 우선순위

```text
거리 조절 / 사선 확보
    → 공격 선택
    → 정지 + 조준선 표시
    → 조준 추적
    → 조준 고정
    → 서버 RayCast + 사격 연출
    → 정지 후딜
    → 거리 조절 / 다음 공격
```

BT 우선순위는 다음과 같다.

1. 사망·기존 스턴 등 행동 불가 상태 처리.
2. 이미 실행 중인 사격/연사/후딜이 있으면 해당 행동 유지.
3. 너무 가까우면 안전한 위치로 후퇴, 너무 멀거나 사선이 막히면 재배치.
4. 거리와 사선이 적합하고 능력 1이 사용 가능하면 능력 1.
5. 기본 공격이 사용 가능하면 기본 공격.
6. 쿨다운 중에는 거리 유지, 이동 후보가 없으면 짧게 대기 후 재판단.

공격 시작 후 플레이어가 가까워져도 후퇴 분기가 공격이나 후딜을 끊지 않는다. 공격 준비·후딜의 이동 잠금은 GA가 소유하고, BT도 Busy 상태일 때 이동을 실행하지 않는다.

## 3. 기본 공격: 조준 단발 사격

### 시작 조건

- 유효한 Player 캐릭터가 있고 최대 사거리 안에 있다.
- 지정 Skeletal Mesh의 사격 소켓이 존재하며 현재 사선이 확보되어 있다.
- 다른 공격·후딜·행동 불가 상태가 아니고 기본 공격 쿨다운이 끝났다.
- 시작 시 타깃을 보관한다. 준비 도중 다른 Player로 갑자기 교체하지 않는다.

### 준비와 조준

`BasicPrepareTime`은 조준선이 나타난 시점부터 실제 발사까지의 **전체 준비 시간**이다. `BasicAimLockTime`은 그 준비 시간에 포함되는 마지막 조준 고정 구간이다.

```text
초기 예시: 전체 준비 2.0초
0.0 ~ 1.4초: 정지 상태로 Player 몸통 방향 추적
1.4 ~ 2.0초: 조준 방향 고정, 조준선 색/밝기 변경
2.0초: 현재 소켓에서 고정 방향으로 1회 RayCast
이후 1.2초: 이동·다음 공격 금지, 후딜
```

- 추적 중에는 몸/상체 회전만 허용하고 보행과 이동 Root Motion은 차단한다.
- 조준 고정 시 타깃 추적과 AI Focus에 의한 자동 재회전을 멈춘다.
- 조준선은 피해가 없는 예고 연출이다. 최종 조준 방향을 보여주어 회피 판단이 가능해야 한다.
- 조준 고정 후 발사 시점의 Player 위치로 다시 조준하지 않는다.
- 공격 준비와 후딜 동안 보스는 정상적으로 피해를 받는다.

### 발사 판정

- 실제 탄환 Actor를 생성하지 않고 서버가 `LineTraceSingleByChannel`에 해당하는 단일 RayCast를 실행한다.
- 시작점은 **발사 시점의 소켓 위치**, 방향은 고정된 조준 방향, 길이는 설정된 최대 사거리이다.
- 발사 직전 시작점·방향·충돌 결과를 하나의 Shot Snapshot으로 확정하여 피해와 사격 연출이 같은 데이터를 사용한다.
- 첫 Blocking Hit가 피해 가능한 Player이면 기존 GAS 피해 흐름을 적용한다. 다른 Player가 먼저 맞으면 그 Player가 피해를 받는다.
- 장애물이 먼저 맞으면 그 위치에서 사격이 끝난다. 관통·자동 명중·추가 보정은 넣지 않는다.
- 플레이어가 사선을 벗어나거나 장애물 뒤로 이동하면 빗나가거나 장애물에 맞는다. 시작 때의 LOS가 실제 명중을 보장하지 않는다.
- 발사 때 타깃이 유효하다면 시작 시 최소 거리/LOS 조건을 다시 적용하여 예고된 사격을 취소하지 않는다. 타깃이 사거리 밖으로 나가도 설정된 Ray 길이까지만 쏜다.
- 한 발의 발사 처리는 1회만 허용한다. 타이머와 연출 콜백이 중복되어도 피해가 중복되면 안 된다.
- 빗나가도 후딜을 수행한다. 총구 섬광·짧은 사격선·충돌 이펙트로 발사를 표현한다.

## 4. 능력 1: 3연속 정밀 사격

기본 공격의 조준선·소켓·RayCast·피해 처리 구조를 재사용하되, 짧은 준비 사격을 3번 반복한다. 플레이어에게 연속 회피를 요구하고, 마지막에는 기본 공격보다 긴 딜타임을 제공한다.

```text
정지
 → 1발 준비 1.0초(추적 0.65 + 고정 0.35) → 사격
 → 0.2초 간격
 → 2발 준비 1.0초(추적 0.65 + 고정 0.35) → 사격
 → 0.2초 간격
 → 3발 준비 1.0초(추적 0.65 + 고정 0.35) → 사격
 → 후딜 2.5초
 → 이동 재개
```

- 각 발의 준비 시작 때 같은 타깃을 다시 추적하고, 각 발의 마지막 구간에서 별도로 조준을 고정한다.
- 전 구간에서 보행을 멈추고 피해 수신을 허용한다. 발 사이 간격에도 후퇴하지 않는다.
- 각 발은 별도의 피해 기회지만 같은 발로 중복 피해를 주지 않는다.
- 초기 발당 피해 계수는 기본 공격의 0.7배를 제안한다. 3발 모두 맞으면 기본 공격의 2.1배이며 실제 수치는 플레이 테스트로 조정한다.
- 기본 공격과 구별되는 준비음과 조준선 연출을 사용한다. 마지막 발 후에는 총을 내리거나 재장전하는 후딜 동작을 보여준다.
- 초기 쿨다운은 Commit부터 12초. 발마다 쿨다운을 추가하지 않고, 기본 공격과 동시에 실행되지 않도록 공통 Busy 상태를 유지한다.

## 5. 이동 구조: 거리 유지와 갑판 제약

이동 거리 판단은 갑판 평면 기준이며, 실제 사거리와 발사 방향은 소켓 기준 3D로 계산한다.

| 항목 | 초기 제안 | 행동 |
| --- | --- | --- |
| 후퇴 진입 거리 | 400cm 미만 | 플레이어 반대 방향의 안전한 위치를 탐색 |
| 선호 거리 | 700cm | 거리 유지 목적지의 기준 |
| 접근 진입 거리 | 1,000cm 초과 | 사격 가능한 위치로 접근 |
| 최대 사거리 | 1,600cm | 이 거리 안에서 사격 시작 가능 |
| 이동 속도 | 220cm/s | 근접 플레이어가 따라잡을 수 있도록 조정 |

- 400~1,000cm 안이고 사선이 확보되면 현재 위치에서 공격할 수 있다. 매번 700cm를 맞추기 위해 이동하지 않는다.
- 후퇴/접근을 시작했다면 선호 거리 주변의 복귀 구간(초기 600~800cm)에 들어올 때 종료한다. 시작·종료 경계를 달리하여 앞뒤 이동 반복을 줄인다.
- 실제 목적지는 `DeckWalkArea`의 보행 가능한 위치에서 선택하고 `DeckWalkRouteComponent`로 이동한다.
- 난간 밖, 발밑 지지가 없는 위치, 캡슐 공간이 막힌 위치, 경로가 없는 위치는 제외한다.
- 장애물로 사선이 끊기면 다른 사격 위치로 재배치한다. 후퇴 위치가 없고 현재 사선은 열려 있으면 제자리 공격을 허용한다.
- 사선도 없고 이동 후보도 없으면 짧은 재시도 대기를 둔다. 무제한 목적지 탐색이나 갑판 밖 이동을 하지 않는다.
- 공격 준비·연사·후딜 중에는 이동 경로 추종을 중지한다. 배의 이동 Base는 유지하여 배의 이동·회전에는 계속 따라간다.

## 6. 딜타임과 피격 정책

| 구간 | 이동 / 공격 | 플레이어의 기회 |
| --- | --- | --- |
| 거리 조절 | 이동 가능 | 추격하거나 다음 사격에 대비 |
| 기본 공격 준비 2.0초 | 이동 정지, 조준만 수행 | 접근·공격 가능. 마지막 0.6초는 조준 회피 가능 |
| 기본 공격 후딜 1.2초 | 이동·공격 금지 | 빗나가게 만든 뒤 안전하게 공격 |
| 능력 1 준비·발 사이 간격 | 전체 이동 정지 | 접근 공격 가능하나 다음 발 위험이 남음 |
| 능력 1 후딜 2.5초 | 이동·공격 금지 | 가장 큰 확정 딜타임 |

일반 피격만으로 매번 준비가 처음부터 재시작되거나 취소되게 하지 않는다. 피해는 정상 적용하고, 실제 행동 중단은 기존 스턴·사망 등 확정된 상태 규칙으로 제한한다. `AShipBossEnemy`에 이미 있는 머리 피격/체력 임계 스턴을 유지할지는 해당 BP 설정과 함께 확인하며, 신규 스턴 패턴으로 확장하지 않는다.

후딜은 단순 공격 쿨다운과 구별한다. 쿨다운이 끝나거나 다른 능력이 준비되어도 후딜 중에는 이동과 새 공격을 시작할 수 없다. 기본 공격 후에는 추가 공격 간격 0.6초를 두어 다음 기본 공격과 능력 1 모두 연속 발동을 제한한다. 이 추가 간격에는 거리 조절이 가능하다.

## 7. 에디터 설정과 시간의 기준

공격별 설정은 해당 GA Blueprint의 Defaults에서, 이동 설정은 보스/이동 Task에서 수정한다. 동일한 설정을 BT와 GA에 각각 복사하여 관리하지 않는다.

| 설정 | 초기값 | 의미 |
| --- | --- | --- |
| `FireSocketName` | `Gun_Muzzle`(가칭) | 캐릭터 Skeletal Mesh에 작성한 사격 소켓 |
| `BasicPrepareTime` / `BasicAimLockTime` | 2.0 / 0.6초 | 전체 준비 / 준비에 포함되는 고정 구간 |
| `BasicRecoveryTime` / `PostBasicAttackGap` | 1.2 / 0.6초 | 정지 후딜 / 후딜 이후 공통 추가 공격 간격 |
| `SkillShotCount` | 3 | 능력 1 발 수 |
| `SkillPrepareTime` / `SkillAimLockTime` | 1.0 / 0.35초 | 각 발의 준비 / 고정 구간 |
| `SkillShotGap` / `SkillRecoveryTime` | 0.2 / 2.5초 | 발 사이 간격 / 마지막 발 이후 정지 후딜 |
| `SkillCooldown` | 12초 | 능력 1의 Commit 기준 쿨다운 |
| `AttackRange` / `BasicDamageCoefficient` / `SkillDamageCoefficient` | 1,600cm / 별도 조정 / 기본의 0.7배 | 공통 최대 사거리와 공격별 피해 계수 |
| `RetreatEnterDistance` / `PreferredDistance` / `ApproachEnterDistance` | 400 / 700 / 1,000cm | 거리 유지 기준 |
| `MoveSpeed` | 220cm/s | 거리 조절 보행 속도 |
| `TelegraphEffect` / `ShotEffect` / `ShotTraceChannel` | 자산·채널 지정 | 조준선·사격 연출·충돌 정책 |

`0 < AimLockTime <= PrepareTime`, `RetreatEnterDistance < PreferredDistance < ApproachEnterDistance < AttackRange`를 검증한다. 준비 시간은 애니메이션 길이와 독립적인 서버 타이머로 결정하며, Montage Hold 구간으로 시간 변경에 대응한다. AnimNotify는 실제 발사의 별도 트리거로 사용하지 않는다.

## 8. 구현 구성과 클라이언트 표현

### 기존 구조 활용

- 캐릭터: `AShipBossEnemy` 기반 신규 `AGunnerBossEnemy`(가칭). 기존 encounter의 Boss class를 새 BP로 지정해 스폰·HostShip·사망·보상 흐름을 재사용한다.
- 공격: `UBossGameplayAbility` 기반 `GA_GunnerBossShot`, `GA_GunnerBossBurst`(가칭). 소켓 조회와 1발 판정·연출 데이터 구성은 작은 공통 함수로 공유한다.
- BT: 신규 전투 Subtree에서 기존 `BTT_ActivateBossAbility`를 활용한다. 구별되는 신규 공격 태그를 사용하여 기존 근접 BasicAttack 선택 로직과 충돌하지 않게 한다.
- 이동: 기존 보스의 Walk 목적지 선택과 `DeckWalkRouteComponent`를 활용하되, 거리 구간을 고려하는 후보 선택을 필요한 만큼 보강한다. 현재 보스 Strafe는 경계/경로 탐색을 하지 않으므로 주 거리 유지 수단으로 사용하지 않는다.
- 조준선: `BossAimLine`(가칭) 복제 Actor가 Mesh/Niagara로 표시한다. 기존 `EnemyShipTimeStopAimLine`의 소스 추적·선 표시 흐름을 참고하되 대포/PlayerShip 전용 로직을 그대로 사용하지 않는다.

현재 RangedEnemy는 소켓에서 화살을 생성하는 구조이므로 그 GA를 직접 총기로 바꾸지 않는다. 소켓 검증과 서버 Bone/Pose 갱신 원칙을 참고하고, 새로운 Hitscan 피해 처리는 보스 GA에서 구현한다. 기존 가이드의 일부 waypoint 설명과 달리 현재 보스 소스는 `FDeckWalkLocation`과 보행면 경로를 사용하므로 이동 구현은 현재 소스를 기준으로 한다.

### 조준선, 충돌, 네트워크 규칙

- AI·공격 단계·발사 시각·피해는 서버가 결정한다. 준비 중 선 표시를 위한 충돌 조회에는 피해를 적용하지 않는다.
- 조준선 Actor에 공격 ID, 단계, 서버 단계 시작/종료 시각, 사격 소켓 정보, 추적/고정 방향과 끝점 정보를 복제한다. 클라이언트가 중간에 보스를 표시하기 시작해도 현재 준비 단계를 복원한다.
- 클라이언트의 선 시작점은 화면에 표시된 보스 소켓을 따라가고, 끝점은 서버 정보를 보간한다. 고정 단계/발사 전환 시 오래된 추적 정보가 남지 않게 한다.
- 배 위에서 고정 조준 방향은 HostShip 로컬 공간으로 보관하고 현재 배 Transform으로 월드 방향을 계산한다. Player 추적은 멈추지만 배의 이동·회전에는 대응한다. 실제 총구 소켓과 같은 방향으로 선과 RayCast를 계산한다.
- 발사 순간에는 Shot Snapshot의 시작점·최종 충돌점을 사격 연출에 전달한다. 피해를 확인한 경우에만 기존 명중 GameplayCue를 실행한다.
- 준비선과 실제 발사는 같은 충돌 정책을 사용한다. 자신과 장착 무기는 제외하지만 갑판 엄폐물·난간·벽은 차단되어야 한다. HostShip 전체를 무조건 Ignore하여 배 구조물을 관통하지 않게 한다.
- 서버에서 보이지 않는 Mesh도 준비/발사 중 소켓 Bone/Pose를 갱신하고, 종료 시 이전 갱신 정책을 복원한다. 소켓이 없으면 Actor 위치로 대체하지 않고 설정 오류로 종료한다.
- 스턴·사망·타깃 무효화·HostShip 파괴·EndPlay에는 타이머, 조준선, 이동/회전 잠금, Busy 상태를 모두 정리한다. 사망 후 예약된 발사가 실행되지 않게 공격 ID를 검증한다. Commit 이전 설정 실패는 쿨다운을 소비하지 않는다.

## 9. 개발 순서와 완료 기준

1. **기본 공격 수직 구현:** 신규 보스 BP/GA와 소켓, 조준선, 서버 단발 RayCast, 피해 처리, 준비/후딜 잠금을 연결한다. 정지된 보스에서 타이밍·회피·피해가 성립하는지 확인한다.
2. **갑판 이동 연결:** 거리 유지 Task와 전투 Subtree를 연결한다. 배가 움직이는 동안 후퇴·접근·엄폐 재배치 및 준비 중 정지를 확인한다.
3. **능력 1 추가:** 동일 사격 처리로 3연사를 구성하고 후딜·쿨다운·공통 Busy를 연결한다.
4. **에디터 및 멀티플레이 검증:** 준비 시간 변경, Dedicated Server/2인 PIE, 배 이동·회전, 중단 정리를 확인하고 전투 템포를 조정한다.

완료 기준:

- 모든 클라이언트에서 준비선이 보이고, 선이 고정된 뒤 옆으로 이동하면 실제로 회피할 수 있다.
- 준비 시간과 후딜을 에디터에서 바꾸면 서버 발사 시점과 클라이언트 연출이 함께 바뀐다.
- 플레이어가 접근해도 준비/연사/후딜 중 후퇴하지 않으며 정상적으로 피해를 받는다.
- 사격선이 장애물에서 끝나고 한 발에 피해를 한 번만 준다. 탄환 Actor는 생성하지 않는다.
- 보스는 안전한 갑판 경로를 따라 거리를 조절하고, 경계나 이동 실패에서 무한 재시도하지 않는다.
- 배가 움직여도 소켓·조준선·실제 판정이 같은 기준을 유지한다.
- 사망·스턴·배 파괴 후 남은 조준선이나 지연 발사, 영구적인 이동 잠금이 없다.
- 기본 공격 준비/후딜과 능력 1의 긴 후딜이 실제 플레이에서 공격 기회로 활용된다.
